歡迎來到我的 GitHub！

## 關於這個 repo

這個 repo 同時是我的 GitHub 個人檔案 README，也是個人入口網頁的原始碼。

- `index.html`：入口網頁（單一檔案，不需建置）
- `.github/workflows/pages.yml`：推送到 `main` 時自動部署到 GitHub Pages

## 如何修改內容

打開 `index.html`，找到 `PROFILE` 區塊，修改名字、介紹、連結與作品即可。

## 啟用 GitHub Pages

1. 到 repo 的 **Settings → Pages**
2. **Source** 選擇 **GitHub Actions**
3. 合併到 `main` 後，網站會自動部署
